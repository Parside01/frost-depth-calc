# Общее описание

Проект представляет собой настольное приложение для расчета глубины промерзания грунта. Оно написано на Python и использует локальную SQLite-базу данных с заранее подготовленными справочниками.

Главная идея приложения: пользователь не вводит климатические данные вручную. Он выбирает населенный пункт, а программа сама берет из базы средние температуры по месяцам, годовую температуру, координаты и справочные коэффициенты.

## Что делает приложение

Приложение позволяет:

- выбрать страну, регион и населенный пункт;
- посмотреть температуры выбранного населенного пункта по 12 месяцам;
- выбрать тип грунта;
- выбрать конструкцию здания и температурный режим помещения;
- рассчитать нормативную и расчетную глубину промерзания грунта;
- выбрать точку на карте и автоматически найти ближайший населенный пункт из базы.

## Основной сценарий работы

1. При запуске приложение открывает локальную базу `data/frost_depth.sqlite3`.
2. Если база еще не создана или в ней не применены последние изменения, запускаются SQL-миграции.
3. Главное окно загружает страны, регионы, населенные пункты, типы грунтов и строительные коэффициенты.
4. Пользователь выбирает значения в форме.
5. Программа показывает месячные температуры выбранного населенного пункта.
6. Пользователь нажимает `Рассчитать`.
7. Программа считает сумму отрицательных температур, нормативную глубину и расчетную глубину.
8. Результат отображается в блоке результатов.

## Что важно понимать заказчику

Это не веб-сайт и не серверное приложение. Программа работает как обычное настольное приложение.

База данных локальная. Она хранится в файле SQLite рядом с проектом. Для изменения справочников и населенных пунктов сейчас используются SQL-миграции, а не отдельный экран редактирования данных.

Карта внутри приложения работает через встроенный браузерный компонент. Сама форма сделана на Qt, но карта является HTML/JavaScript-страницей, встроенной в окно.
