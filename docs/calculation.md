# Логика расчета

Расчет находится в `frost_depth/domain/calculation.py`.

Главный класс:

```text
FrostDepthCalculator
```

Он получает подготовленные входные данные и возвращает результат расчета.

## Входные данные

Для расчета нужны:

- название населенного пункта;
- среднегодовая температура;
- 12 месячных температур;
- коэффициент грунта;
- коэффициент здания.

Эти данные собираются из нескольких мест:

- температуры и название населенного пункта приходят из таблицы `settlements`;
- коэффициент грунта приходит из таблицы `soil_types`;
- коэффициент здания приходит из таблицы `building_coefficients`.

## Проверки перед расчетом

Перед расчетом код проверяет:

- месячных температур должно быть ровно 12;
- коэффициент грунта должен быть больше нуля;
- коэффициент здания должен быть больше нуля.

Если данные некорректные, расчет останавливается с ошибкой. В интерфейсе такая ошибка показывается пользователю через предупреждение.

## Индекс промерзания

Сначала программа считает сумму отрицательных месячных температур.

Пример:

```text
[-3.7, -2.3, 1.4, 7.5, ..., -1.1]
```

В расчет идут только отрицательные значения:

```text
3.7 + 2.3 + 1.1 = 7.1
```

Положительные месяцы не увеличивают индекс промерзания.

## Нормативная глубина

Нормативная глубина считается так:

```text
нормативная глубина = коэффициент грунта * sqrt(индекс промерзания)
```

В коде используется `math.sqrt`.

## Расчетная глубина

Расчетная глубина учитывает коэффициент здания:

```text
расчетная глубина = коэффициент здания * нормативная глубина
```

То есть сначала считается базовое значение по климату и грунту, а затем оно корректируется под тип здания и температурный режим.

## Округление

Все ключевые числовые результаты округляются до двух знаков:

- индекс промерзания;
- нормативная глубина;
- расчетная глубина.

В интерфейсе результаты также показываются с двумя знаками после запятой.

## Где находится связь расчета с интерфейсом

Сам калькулятор не знает про кнопки, выпадающие списки и базу данных.

Связующий слой находится в `frost_depth/application/services.py`.

`CalculationService` получает выбранные значения из интерфейса, находит нужные коэффициенты в справочниках, собирает `CalculationInput` и вызывает `FrostDepthCalculator`.
