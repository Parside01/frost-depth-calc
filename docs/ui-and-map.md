# Интерфейс и карта

Графический интерфейс находится в папке `frost_depth/ui`.

Основные файлы:

- `main_window.py` - главное окно приложения;
- `map_widget.py` - Qt-виджет, который встраивает карту;
- `map_assets/index.html` - HTML-страница карты;
- `map_assets/js/map.js` - логика карты на JavaScript;
- `map_assets/css/map.css` - стили карты и подписей.

## Главное окно

Класс `MainWindow` строит форму приложения.

В окне есть:

- выбор страны;
- выбор области;
- выбор населенного пункта;
- выбор конструкции здания;
- выбор температуры внутри помещения;
- выбор типа грунта;
- карта;
- кнопка расчета;
- блок результатов;
- таблица температур по месяцам.

Интерфейс построен на стандартных Qt-виджетах: `QComboBox`, `QPushButton`, `QLabel`, `QTableWidget`, `QGroupBox`.

## Загрузка списков

При открытии окна вызывается `_load_data`.

Она загружает:

- страны и регионы из `SettlementRepository`;
- населенные пункты из `SettlementRepository`;
- конструкции и температурные диапазоны из `ReferenceRepository`;
- типы грунтов из `ReferenceRepository`.

Когда пользователь меняет страну, перезагружается список регионов. Когда меняется регион, перезагружается список населенных пунктов.

## Таблица температур

Таблица температур показывает два ряда:

- названия месяцев;
- температуру выбранного населенного пункта за каждый месяц.

Таблица только для просмотра. Пользователь не редактирует температуры через интерфейс.

## Карта внутри приложения

Карта реализована не как обычный Qt-виджет, а как HTML-страница внутри `QWebEngineView`.

Это позволяет использовать Leaflet и OpenStreetMap, как в веб-приложениях, но показывать карту прямо в настольной программе.

## Как Python передает данные в карту

Python формирует список ближайших населенных пунктов:

```text
name, region, country, latitude, longitude
```

Потом этот список превращается в JSON и передается в HTML/JavaScript.

Если карта открывается впервые, Python подставляет данные в HTML-шаблон. Если карта уже загружена, Python вызывает JavaScript-функцию:

```text
window.updateNearbySettlements(...)
```

## Как карта сообщает о клике в Python

Для обратной связи используется `QWebChannel`.

Поток такой:

1. Пользователь кликает по карте.
2. JavaScript получает координаты клика.
3. JavaScript вызывает `bridge.selectPoint(lat, lon)`.
4. Python-объект `MapBridge` принимает координаты.
5. `SettlementMap` испускает сигнал `pointSelected`.
6. `MainWindow` вызывает `_select_nearest_settlement`.
7. Программа находит ближайший населенный пункт и выбирает его в форме.

## Неочевидные детали

Карта использует OpenStreetMap-тайлы по сети. Если интернета нет, логика выбора координат может остаться, но фон карты может не загрузиться.

На карте показываются не все населенные пункты из базы, а только несколько ближайших. В `MainWindow` используется лимит `NEARBY_SETTLEMENT_LIMIT = 3`.

При выборе точки на карте окно временно ставит флаг `_selecting_from_map`. Это нужно, чтобы обновление выпадающих списков не вызвало лишнюю автоматическую перестройку карты.
