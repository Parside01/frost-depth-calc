# Используемые библиотеки

Проект использует небольшой набор библиотек. Они закрывают три основные задачи: настольный интерфейс, встроенную карту и работу с базой данных.

## PySide6

`PySide6` - библиотека для создания настольных приложений на Qt.

В проекте она используется для главного окна, полей выбора, кнопок, таблицы температур, сообщений об ошибках и общей компоновки интерфейса.

Основные элементы:

- `QApplication` запускает графическое приложение;
- `QMainWindow` является основой главного окна;
- `QComboBox` используется для выпадающих списков;
- `QTableWidget` показывает температуры по месяцам;
- `QMessageBox` показывает предупреждения пользователю;
- `QGroupBox`, `QVBoxLayout`, `QGridLayout` отвечают за расположение блоков на экране.

## PySide6-WebEngine

`PySide6-WebEngine` нужен для встраивания веб-страницы внутрь настольного приложения.

В проекте он используется для карты. Класс `QWebEngineView` открывает локальный HTML-файл с картой и показывает его как часть Qt-интерфейса.

Важный момент: без WebEngine карта не смогла бы работать как интерактивная HTML/JavaScript-страница внутри приложения.

## SQLAlchemy

`SQLAlchemy` используется для работы с SQLite-базой данных.

В проекте применяется не ORM-стиль с классами-таблицами, а SQLAlchemy Core:

- таблицы описаны через `Table`, `Column`, `ForeignKey`, `UniqueConstraint`;
- запросы собираются через `select`, `insert`, `text`;
- подключение создается через `create_engine`.

Такой вариант хорошо подходит для учебного проекта: структура базы описана явно, а запросы остаются понятными.

## SQLite

SQLite - это файловая база данных. Отдельный сервер базы данных не нужен.

Основной файл базы:

```text
data/frost_depth.sqlite3
```

При тестах используется специальный режим `:memory:`. В этом режиме база создается в оперативной памяти и исчезает после окончания теста.

## Leaflet и OpenStreetMap

Карта внутри приложения построена на JavaScript-библиотеке Leaflet.

Leaflet отвечает за:

- отображение карты;
- маркеры населенных пунктов;
- подписи рядом с маркерами;
- обработку клика по карте;
- подстройку масштаба под выбранные точки.

Картографические тайлы загружаются с OpenStreetMap. Поэтому сама форма приложения может работать локально, но для отображения фона карты нужен доступ к интернету.

## unittest

`unittest` - стандартная библиотека Python для тестов.

В проекте тестируются:

- формула расчета;
- выборка населенных пунктов из базы;
- поиск ближайшего населенного пункта;
- получение строительных коэффициентов.

## Стандартные модули Python

Также используются стандартные модули:

- `pathlib` для работы с путями к файлам;
- `math.sqrt` для квадратного корня в формуле;
- `dataclasses` для простых неизменяемых моделей данных;
- `json` для передачи данных из Python в JavaScript-карту;
- `sys` для передачи аргументов запуска в Qt-приложение.
